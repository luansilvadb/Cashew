# Cashew End-User Documentation Framework

This directory contains the end-user manuals and reference guides for the Cashew ERP and Budgeting application.

## Directory Structure

- /manuals/introduction/ - Getting started and setup guides.
- /manuals/transactions/ - Expense and income recording.
- /manuals/budgets/ - Financial limit setting and monitoring.
- /manuals/accounts/ - Multi-wallet and currency management.
- /manuals/goals/ - Savings goals and debt/loan tracking.
- /manuals/reports/ - Analytics, graphs, and summary insights.
- /manuals/recurring/ - Subscriptions and repetitive payments.
- /manuals/sync-security/ - Backup, sync, and biometric privacy.
- /manuals/import-export/ - CSV and Google Sheets integration.
- /manuals/advanced/ - Automation, custom titles, and app links.

## Documentation Standards

- Files must be in PHP format and included dynamically by /public/user-manuals.php.
- 500-line hard limit per file.
- Use professional, instructional, and literal-minded tone.
- Bold UI elements like **buttons**, **menus**, and **fields**.
- Include Conceptual Overview, Procedural Steps, and Technical Reference.
